## 📋 О проекте

**Технологическая система управления производством** - это комплексное решение для автоматизации ключевых процессов технологического отдела предприятия по производству средств защиты растений (гербициды, фунгициды, инсектициды).

Система разработана для трех категорий пользователей и обеспечивает полный цикл управления производством: от создания рецептуры до контроля качества готовой продукции.

## 🎯 Основные возможности

### 👨‍💼 Модуль технолога
| Функция | Описание |
|---------|----------|
| 📦 **Карточки продукции** | Ведение справочника готовой продукции и сырья |
| 📝 **Рецептуры** | Создание, версионирование, контроль состава (сумма 100%) |
| 📋 **Технологические карты** | Пошаговые инструкции для производства |
| 📊 **Производственные заказы** | Формирование заказов, расчет потребности в сырье |
| 🏭 **Партии** | Управление партиями, отслеживание статусов |
| ⚙️ **Настройка экструдера** | Создание профилей для оборудования |
| 📄 **Отчеты** | Формирование PDF/Excel отчетов |
